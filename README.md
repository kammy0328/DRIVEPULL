# DRIVEPULL

구글 드라이브 링크를 붙여넣으면 안에 든 파일 목록을 불러와서, 고른 파일만 원하는 경로에 빠르게 받는 Windows 앱.

## 기능

- **링크 붙여넣기 → 자동 목록**: 폴더(하위 폴더 포함), 단일 파일, 공유 드라이브, 바로가기 지원
- **선택 다운로드**: 체크박스 트리, 이름·확장자 검색(`.mov` 등), 선택 용량 합계 표시
- **썸네일 보기**: 영상·이미지 미리보기 카드, 폴더는 안쪽 첫 파일로 미리보기, 해상도(4K·FHD)·길이 배지, 카드 크기 조절. 검색하면 하위 폴더까지 펼쳐서 맞는 파일만 표시
- **멀티 커넥션 + 자동 조절**: 파일 하나를 여러 갈래로 나눠 동시에 받음. 8연결로 시작해 속도가 오르는 동안 늘리고(빠르게 오르면 두 배씩), 효과가 없으면 되돌리고, 구글이 요청을 제한하면 줄임. 찾은 값은 다음 파일 시작값으로 재사용. 먼저 끝난 연결이 남은 구간을 나눠 가져가서 끝까지 속도 유지
- **대용량 즉시 시작**: 40GB 같은 큰 파일도 디스크 공간을 0으로 채우지 않고 바로 잡음 (NTFS sparse)
- **일시정지 / 이어받기**: 진행 상태를 `파일명.drivepull.json`에 저장해서 앱을 껐다 켜거나 네트워크가 끊겨도 이어받음
- **검증**: 로그인 모드에서 완료 후 MD5 대조 (손상 시 자동으로 다시 받게 표시)
- **구글 제한 대응**: "Too many users..." 제한이 걸리면 받은 부분은 그대로 두고 10분 → 30분 → 1시간 → 2시간 뒤 자동으로 이어받음. 로그인 상태면 내 드라이브 임시 사본으로 바로 받고 사본은 자동 삭제. 로그인 없는 모드는 요청 수를 줄이려고 파일당 최대 6연결
- **검증은 백그라운드**: MD5 검증 중에도 다음 파일 다운로드가 바로 시작됨
- **HDD 자동 감지**: 저장 위치가 HDD면 파일당 4연결로 제한 (여러 위치 동시 쓰기로 느려지는 것 방지)
- **구글 문서**: 문서·스프레드시트·프레젠테이션은 docx·xlsx·pptx로 내보내기
- 폴더 구조 유지 / 한 폴더에 모으기, 같은 파일이 이미 있으면 건너뛰기, 260자 넘는 긴 경로 지원

## 두 가지 모드

| | 로그인 없이 | 구글 로그인 |
|---|---|---|
| 대상 | "링크가 있는 모든 사용자" 공개 링크 | 공개 링크 + 내 계정에 공유된 비공개 폴더 |
| 목록 | 공개 폴더 페이지 해석, 용량은 파일별로 확인 | Drive API (빠르고 정확) |
| MD5 검증 / 할당량 우회 / 구글 문서 | X | O |

로그인하면 공개 링크도 자동으로 API 방식으로 받음.

## 설치 (사용자)

최신 버전 바로 받기: https://github.com/kammy0328/DRIVEPULL/releases/latest/download/DRIVEPULL.exe (설치 필요 없음)

`drivepull/config.py` 의 `APP_VERSION` 을 올려서 main 에 푸시하면 빌드 후 해당 버전 Release 가 자동 생성됨. 같은 버전으로 다시 푸시하면 exe 만 교체.

설정·로그인 토큰·대기열은 `%APPDATA%\DRIVEPULL\` 에 저장됨.

## 구글 로그인 준비 (최초 1회)

구글 로그인에는 내 Google Cloud 프로젝트의 OAuth 클라이언트가 필요함.

1. https://console.cloud.google.com 에서 새 프로젝트 생성
2. **API 및 서비스 → 라이브러리** 에서 **Google Drive API** 사용 설정
3. **OAuth 동의 화면**: 사용자 유형 *외부*, 앱 이름 `DRIVEPULL`, 테스트 사용자에 로그인할 구글 계정 추가
4. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID → 애플리케이션 유형: 데스크톱 앱**
5. 생성된 JSON 다운로드 후 둘 중 하나:
   - 앱의 **설정 → client_secret.json 불러오기** (내 PC에서만 쓸 때)
   - GitHub 저장소 **Settings → Secrets and variables → Actions** 에 `GOOGLE_OAUTH_CLIENT_ID`, `GOOGLE_OAUTH_CLIENT_SECRET` 등록 → 다음 빌드부터 exe에 내장되어 바로 로그인 가능

> 동의 화면이 *테스트* 상태면 구글 정책상 로그인이 7일마다 만료됨. 계속 쓰려면 동의 화면을 *프로덕션으로 게시*. 이 경우 로그인할 때 "확인되지 않은 앱" 경고가 뜨는데, **고급 → DRIVEPULL(으)로 이동** 을 누르면 됨.

## 개발

```bash
pip install -r requirements.txt
python run.py
python -m pytest -q tests
```

main 브랜치에 푸시하면 GitHub Actions가 테스트 후 `DRIVEPULL.exe` 를 빌드하고 Release 에 올림.

```
drivepull/
  engine.py     분할 다운로드 엔진, 대기열(일시정지·이어받기·재시도)
  drive.py      링크 해석, 목록(API/공개), 다운로드 소스
  auth.py       구글 OAuth 로그인
  service.py    엔진·로그인·API 연결
  ui/           PySide6 다크 UI
```

## 속도 팁

- 기본값: 자동 조절 켜짐, 파일당 최대 16연결, 동시 3파일. 회선이 아주 빠르면 설정에서 최대값을 32로
- 작은 파일이 많으면 동시 파일 수를 늘리는 편이 빠름 (작은 파일은 4MB당 1갈래까지만 나뉨)
- 엔진 처리 한계: TLS 16연결 기준 약 570MB/s (2코어 테스트 환경, 서버와 CPU 공유). 1Gbps 회선에서는 CPU 약 0.25코어만 사용
- exFAT 외장 드라이브는 sparse 파일을 지원하지 않아 큰 파일 초반 속도가 느릴 수 있음. NTFS 권장
